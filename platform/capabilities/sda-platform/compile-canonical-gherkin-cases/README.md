# Compile canonical Gherkin cases

This admitted capability owns deterministic official case compilation from one
lossless parse. Its scenarios cover ordinary and expanded cases, stale lineage,
and reproducibility. It does not execute cases or admit SDA meaning.

The target-neutral provider is implemented at
`tools/src/gherkin/application/canonical-gherkin-compiler.ts` and is admitted
only with the capability-owned compiler conformance receipt.
