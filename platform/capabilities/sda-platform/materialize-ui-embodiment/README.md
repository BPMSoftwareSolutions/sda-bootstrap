# Materialize UI embodiment

Phase H introduces a shared, target-neutral plan applier beneath the TypeScript
React and browser DOM reference providers. Both providers consume only
`ui-embodiment-plan.v1`; neither reads declared authority, semantic presentation,
successor IR, frozen consumer recipes, or v2 protocol objects.

The reference providers are structurally admitted. Their testimony proves native
role selection, event and accessibility attachment, composition, and preservation
of adaptation instructions. It does not claim browser-native execution proof;
that remains a separate admission gate.

Phase I increment 1 adds a shared C# plan parser/projector beneath WPF and
Avalonia. The target adapters construct native controls, attach declared
activation and accessibility metadata, preserve adaptation instructions, and
remove controls when semantic authority is deleted. Both are structurally
admitted; successor-specific out-of-process UI Automation/headless testimony
is still required before either may claim `NATIVE_PROOF_ADMITTED`.
