# Derive semantic corpus records

This proposed capability owns deterministic semantic object, relationship, and
finding derivation from one snapshot and admitted ingestion receipts. Its
scenarios cover ordinary derivation, open references, prohibited authority
bases, mixed generations, and reproducibility.

No handwritten provider is admitted by this source declaration. The Node
realization under `projected/` is emitted by the ordinary governed
consumer-projection circuit and bound through its projected application
binding. It compiles the exact admitted generic ontology, profile, rule set,
and declared resource order into static semantic-transformation expressions.

The generated fixture suite currently passes nine tests: the observation
guard; canonical derivation; discovery-order independence through declared
resource order; open-reference non-invention; exact rule-set binding; and
mixed-snapshot, receipt-document, source-byte, and representation-digest
rejections. The strict request contract prevents source-class escalation, and
the exact compiled rule-set digest prevents a prohibited basis from entering
the projected circuit. The projection conformance receipt is `ADMITTED` with
all 12 partitions `SATISFIED`.
