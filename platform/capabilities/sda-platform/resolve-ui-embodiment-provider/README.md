# Resolve UI embodiment provider

This pure capability admits a digest-bound target profile and provider catalog,
then resolves one compatible provider by complete feature support, proof
capability, requested identity, and deterministic priority. Missing support and
top-priority ties reject explicitly.

The checked-in headless provider is `PLANNING_ONLY`. It proves catalog and plan
behavior but makes no materialization, structural-observation, native-proof, or
target-conformance claim.
