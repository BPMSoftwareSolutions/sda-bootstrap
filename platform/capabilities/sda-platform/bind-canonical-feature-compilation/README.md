# Bind canonical feature compilation

This admitted capability binds mutually consistent source, syntax, case,
profile, compiler, and grammar evidence into one immutable compilation. Its
scenarios cover binding, mismatch, stale authority, and reproducibility.

The resulting receipt makes no projection, execution, or behavioral claim.
The target-neutral provider is implemented at
`tools/src/gherkin/application/canonical-gherkin-compiler.ts`.
