# Operate a semantic corpus artifact repository

This proposed capability owns immutable publication, exact-address reads,
retention, and current-pointer compare-and-swap as one cohesive repository
boundary. Its scenarios cover success, conflict, corruption or absence,
retained snapshots, closure enforcement, and reproducible addressing.

This is retained Wave 8 authority, not a Wave 0 or Wave 1 runtime prerequisite.
No filesystem implementation is admitted by this source declaration. A future
projected realization remains blocked on dedicated governed exclusive-create
and compare-and-swap effect authority.

Earlier waves publish immutable generated projection artifacts through the
already-admitted batch filesystem shaper and verify them through governed
repository observation. Their serial build and promotion receipts are evidence
about generated artifacts; they do not claim this repository capability or a
mutable current-pointer runtime.
